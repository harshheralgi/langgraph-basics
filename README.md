# 🚀 Getting Started

## 1. Clone the Repository

```bash
git clone <your-repo-url>
cd <repo-name>
```

---

## 2. Install Dependencies

Using uv:

```bash
uv sync
```

Or using pip:

```bash
pip install -r requirements.txt
```

---

## 3. Set Environment Variables

Create a `.env` file:

```env
GROQ_API_KEY=your_api_key_here
```

---

## 4. Run Jupyter Notebook

```bash
jupyter notebook
```
